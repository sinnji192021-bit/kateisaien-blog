# えいこうの家庭菜園ノート

Cloudflare Pages で公開している静的ブログ（`git push` すると自動デプロイ）。

## 新しい記事を追加する手順

**1. 記事HTMLと画像を置く**

- `articles/09-mise-jimai.html` … 既存記事をコピーして中身を差し替えるのが早い
- `images/09/` … アイキャッチと本文の図解

**2. `scripts/articles.json` に1件足す**

```json
{
  "slug": "09-mise-jimai",
  "section": "monthly",
  "date": "2026-08-12",
  "featured": true,
  "cat": "今月の作業", "catcolor": "r",
  "card": "【保存版】夏野菜の店じまい🍂 抜く順番と、秋がラクになる土のリセット3ステップ",
  "short": "【保存版】夏野菜の店じまい🍂",
  "desc": "夏野菜、いつ抜く？ 抜く順番は3組に分けるだけ。抜いた茎は捨てないでください。",
  "thumb": "images/09/第9回_図0_アイキャッチ.png"
}
```

| 項目 | 意味 |
|---|---|
| `slug` | ファイル名（`.html` は書かない） |
| `section` | `monthly` 今月やること／`start` はじめての方／`trouble` 悩み対策／`learn` 育てて学ぶ |
| `featured` | `true` にすると TOP 最上部の大きい「今月の必読」枠に出る（1件だけ） |
| `cat` / `catcolor` | カテゴリ名と色（`r`=赤／`g`=緑） |
| `card` | TOPのカードに出す見出し |
| `short` | 「あわせて読みたい」に出す短いタイトル |
| `desc` | カードの説明文（2行で切れる） |
| `thumb` | サムネ画像のパス |
| `related` | 省略可。指定しなければ**同じカテゴリ優先で自動選択** |

**3. ビルドを走らせる**

```bash
cd ~/Documents/kateisaien-blog && python3 scripts/build.py
```

これだけで次が全部そろいます。

1. TOPの注目記事（大きいカード）
2. TOPのセクション別カード一覧（新しい記事ほど上・NEWバッジ自動）
3. 記事の「日付・カテゴリ・読了時間」行
4. 記事の目次（h2から自動生成・アンカーも自動）
5. 記事末尾の「あわせて読みたい」3本
6. `sitemap.xml`

**4. 確認して公開**

```bash
python3 -m http.server 8123
```

`http://localhost:8123/` で確認 → 問題なければ `git push`（＝Claudeに「PUSH」と言えばOK）。

## 仕組みのメモ

- 差し込み位置は `<!-- BUILD:CARDS -->` のようなHTMLコメントで管理。**目印の外を手で書き換えても消えません**。
- 記事HTMLやサムネがまだ無い記事は、**警告を出して自動でスキップ**します（書きかけでもTOPは壊れない）。
- 読了時間は本文の文字数から実測（1分=550字）。手で書く必要はありません。
